## Important caveats
1. "GR No." for GRs located through archive.org is the **portal unique code** (YYYYMMDDHHMMSS + dept suffix), not the departmental number; departmental numbers are given only where read in the PDF.
2. Many PDF bodies were NOT read (only titles/dates from listings); each entry is tagged. All summaries need verification against the original before use in a note or affidavit.
3. Dept sites that block automated fetching (robots): krishi.maharashtra.gov.in, labour.maharashtra.gov.in, maitri, cultural.maharashtra.gov.in — their URLs are included as seen.
4. WebSearch budget (200 per turn) was exhausted; some planned searches (minimum-wage notifications, MSEDCL, mining, sugar policy, cultural affairs) could not be run.
