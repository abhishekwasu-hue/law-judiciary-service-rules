# 00-INDEX — Case-law library for State replies in Bombay HC service matters of court staff (Group A–D)

Compiled 28.10.2026 for the Law & Judiciary Department (Mantralaya) desk that files affidavits / parawise replies. Companion to the rules/GR files 01–82 in this folder. Each group file has: (1) a table of cases (name | citation | court/date | one-line ratio | verification status), (2) details per case — ratio, verbatim paragraphs where the official text was opened, "how the State uses / how petitioners use", (3) a drafting checklist, (4) a Marathi gist.

**Verification legend used in every file**
- ✔ official text opened in this research (api.sci.gov.in / main.sci.gov.in / HC-site mirror of the SC judgment) — paragraph quotes are verbatim.
- ◐ only a secondary source (LiveLaw, SCC Online blog, Verdictum, LegitQuest, press) opened — *citation from secondary source — verify* before quoting.
- ✖ cited from standard reporters or from the department's own brief; not opened — *verify* (name, citation, paragraph) before pleading.

## Quick map: petition type → files
- Notional increment for 30-June/31-Dec retirees → A (Mundinamani, Siddaraj), B (delay), I (in rem/in personam).
- Recovery of excess pay after re-fixation → A (Rafiq Masih, Jagdev Singh), I (negative equality).
- Shetty Commission scale / parity of City Civil, Small Causes, District Court staff → H (Court Stenographers 2002, Dhawale, Ghule), I (equal pay), B (delay), A (arrears cap).
- Daily-wage / outsourced / Court Manager regularisation → C (Umadevi, Jaggo, Court Managers 16.05.2025 in H), I (Jagjit Singh).
- Promotion / DPC delay / sealed cover / reservation stream → D, G (Jankiraman), library file 31.
- ACP/TBP denial (refusal of promotion, exam, DE) → D (Manju Arora), library files 10–11.
- Pension/gratuity withheld; interest; family pension arrears; OPS vs NPS → E, A (Tarsem Singh), library files 44–48.
- Compassionate appointment → F, library file 36.
- Suspension/charge-sheet/penalty → G, library files 51–52.

## मराठी सारांश
- ही सूची न्यायालयीन कर्मचाऱ्यांच्या सेवाविषयक याचिकांत शासनाच्या शपथपत्रासाठी लागणाऱ्या सर्वोच्च व मुंबई उच्च न्यायालयाच्या निकालांची, विषयानुसार (अ ते इ) नऊ फाइल्समध्ये विभागलेली आहे.
- प्रत्येक फाइलमध्ये: प्रकरणांची तक्ता-सूची, प्रत्येक निकालाचे सार, अधिकृत मजकूर उघडलेला असल्यास परिच्छेदांचे शब्दशः उतारे, "शासन कसे वापरते / याचिकाकर्ते कसे वापरतात", मसुदा-तपासणी सूची व मराठी सारांश.
- पडताळणी चिन्हे: ✔ अधिकृत मजकूर पाहिला; ◐ फक्त दुय्यम स्रोत (पडताळावे); ✖ संदर्भ-ग्रंथ/विभागीय फाईलवरून, मजकूर न पाहिलेला (उद्धृत करण्यापूर्वी पडताळावे).
- विभागीय फाईलमधील मुंबई उच्च न्यायालय प्रकरणे (खिल्लारी, बांदेकर, 8224/2022, बिरादार, अहिरे, तुपे) ऑनलाइन सापडली नाहीत — प्रमाणित प्रती घेऊन नोंद पूर्ण करावी.
