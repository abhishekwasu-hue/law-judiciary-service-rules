## Research constraints (read before relying on these files)
1. Only WebSearch/WebFetch were available; the shell has no access to government sites.
2. **gad.maharashtra.gov.in, gr.maharashtra.gov.in, finance.maharashtra.gov.in/en/… and mahakosh.maharashtra.gov.in block automated fetching (robots.txt)**. The Marathi (non-/en/) Finance pages and the official S3WaaS CDN (`cdnbbsr.s3waas.gov.in`, which serves gad/finance uploads) were fetchable, but only when the exact PDF URL appeared in a search result.
3. Bombay High Court judgment URLs exceed the fetch tool's URL-length limit, so judgments quoting rule text could not be used.
4. The fetch tool returns paraphrase and ≤125-character quotes, and several official PDFs are scanned (no text layer). **No file contains long verbatim rule text; every rule description is a summary to be verified against the printed GAD/Finance edition.**
