## 0. Never stop — deliver with warnings [I4.26] (ENGINE_PROMPT rules 2, 5, 9)
- status.json "failed" ONLY when no output could be produced (pages unreadable, nothing built). Otherwise "done"; each unresolved problem = a `warnings` line "पडताळणी अपूर्ण — <what, where>" (lint/verify/extract/part1 not clean after the caps, C R/file no. missing, GR not found, instruction vs binding rule, part 1 incomplete for time).
- Caps per problem: orchestrator 2 + drafter 2 (mechanical repairs: fixer 1 + drafter 1) + drafter_strong 1 (if set) attempts; then warning, go on, never loop.
- "Ask" / "discuss first" ([I3.2], [SOP2] सांकेतांक) = a `warnings` line + a Study part 4 question; work goes on.
- C R no./year/file no. missing in case.json and on every page -> PREFIX `Case<id>_<year>`, ref_no `संकिर्ण-<year>/____/प्र.क्र.____/का.6`, warning; never a reason to stop, refuse or fail. Unclear: [I1.4].
- Instruction vs a binding rule -> the rule wins in the files; warning "पडताळणी अपूर्ण — सूचना '…' नियम §… मुळे लागू केली नाही".
- Review: 1 review + 1 re-review. The reviewer runs `python3 tools/lint_spec.py /tmp/work/spec.json` to LINT OK before hashing; a substantive error -> approved=false with `reason` (+ `redraft` points) -> ONE drafter redraft -> re-review; still false -> delivered, warning "अंतिम पडताळणी (Opus) मान्यता नाही — वापरण्यापूर्वी तपासा: <reason>".
