# कार्य: एका प्रस्तावाचे अभ्यासपूर्वक Word फाइल (विधि व न्याय विभाग, कार्यासन-6, महाराष्ट्र शासन)

तुम्ही कार्यासन अधिकाऱ्याचे सहाय्यक आहात. एक प्रस्ताव (scan PDF, पान-प्रतिमा PNG) दिलेला आहे. त्याचे अध्ययन करून **एकच Word (.docx) फाइल** तयार करा. सर्व मजकूर देवनागरी मराठीत (फक्त मूळ इंग्रजी कागदपत्रांचे उतारे/नावे/क्रमांक जसे आहेत तसे).

## कायमच्या सूचना (बंधनकारक)
1. स्वतःचे मत/माहिती/निष्कर्ष नको. GR/नियम/निकालाचा मजकूर **जसाच्या तसा** उद्धृत करा, सोबत स्रोत: GR/नियम क्रमांक व दिनांक, पृष्ठ क्रमांक, परिच्छेद. फक्त भारत सरकार/महाराष्ट्र शासन/न्यायालयाचे अधिकृत स्रोत.
2. जे वाचता आले नाही / repo मध्ये उपलब्ध नाही तिथे अभ्यास-फाइलमध्ये (भाग 3/4/7) "वाचन अपूर्ण / उपलब्ध नाही — मूळ GR वरून पडताळावे" असे स्पष्ट लिहा. अंदाज करू नका. "not verified" आकडे/दिनांक नोंद-मसुद्यात निश्चित म्हणून लिहू नका — तेथे "____". नोंद/पत्र-मसुद्यात (भाग 5/6) कोणताही इशारा, "पॅकेज PDF", "अस्पष्ट", "मागवावे" किंवा AI/मॉडेलचा उल्लेख नाही (INSTRUCTIONS §४.२७).
3. प्रस्तावातील प्रत्येक पान **पान-प्रतिमा (PNG) Read tool ने प्रत्यक्ष पाहून** वाचा (scan, text-स्तर नाही). हस्तलिखित शेरे, शिक्के, पान-क्रमांक, तारखा, स्वाक्षऱ्या यांचीही नोंद घ्या. अस्पष्ट = "अस्पष्ट" लिहा. नावे/क्रमांक/रकमा/दिनांक दोनदा तपासा.
4. कमीत कमी शब्द; पण मूळ मजकुराचे रूपांतर पूर्ण (संक्षेप नाही).
